# desk-bell

A minimal static desk bell stopwatch app.

## Run locally

Open `index.html` in a browser,
or serve the folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.

## Features

- Stopwatch with start / pause / resume / clear
- Add custom bell times (in seconds)
- Remove bell times
- Bell sound is triggered when elapsed time reaches each configured bell time
